# 隱私權政策

最後更新：2026 年 10 月 12 日

本政策說明 **Video Lasso**（以下稱「本工具」）及其官方網站如何處理資料。本工具由個人開發者許耀庭（以下稱「開發者」或「我們」）開發與維護。我們依《個人資料保護法》（以下稱「個資法」）等中華民國（台灣）法律處理個人資料。使用本工具即表示你了解本政策；使用條件請見[服務條款](terms.html)。

**簡單說：** 本工具在你的瀏覽器裡運作，沒有帳號、沒有分析追蹤，我們也沒有接收你瀏覽紀錄或影片內容的伺服器。只有在你啟用 Pro 授權碼時，才會與付款平台 Lemon Squeezy 往來。

## 1. 我們「不」蒐集的資料

- 你瀏覽的網址、網頁內容與搜尋紀錄。
- 你偵測、下載、錄製的影片、音訊或字幕內容，以及下載清單。
- 你的姓名、帳號、定位、裝置識別碼，或任何使用行為分析與廣告資料。
- 你的信用卡等付款資訊（由 Lemon Squeezy 處理，我們不會取得）。

本工具沒有內建任何統計、分析、廣告或錯誤回報服務。

## 2. 儲存在你自己瀏覽器中的資料

下列資料只存在你的瀏覽器內（`chrome.storage` 與 IndexedDB），開發者無法讀取：

| 資料 | 用途 | 存放位置 |
| --- | --- | --- |
| 偏好設定（語言、主題、字型、預覽方式、字幕語言偏好、Logo 與圖示顏色） | 保存你的設定 | storage.local |
| 目前分頁偵測到的影片網址與標題（暫時性） | 顯示可下載清單 | storage.session（關閉瀏覽器即清除） |
| 下載進度與最近 200 筆下載紀錄（標題、縮圖、來源頁網址、檔名、大小、時間） | 顯示「進行中」與「紀錄」 | storage.local，可在擴充功能內刪除 |
| 你選擇的儲存資料夾的存取權（資料夾控制代碼） | 把檔案存到你指定的位置 | IndexedDB |
| 今日剪輯與錄製的使用次數 | 實施免費版每日限制 | storage.local 與 storage.sync |
| Pro 授權資訊（授權碼、方案、到期日、Email、裝置名稱、已啟用裝置數、最近驗證時間） | 啟用並維持 Pro 功能 | storage.local |

說明：

1. **storage.sync** 由你的瀏覽器帳號（Google 或 Microsoft）提供，內容可能被同步到你登入同一帳號的其他裝置，並儲存在該公司的伺服器；這屬於瀏覽器的功能，不由我們控制，開發者也無法存取。本工具只把「今日剪輯與錄製次數」放進 sync，目的是避免重新安裝後次數被歸零。
2. 解除安裝擴充功能後，上述本機資料會由瀏覽器一併刪除。

本工具只在下列情況與外部連線：

| 對象 | 何時 | 傳送內容 |
| --- | --- | --- |
| **Lemon Squeezy**（api.lemonsqueezy.com） | 你啟用、定期驗證或登出授權碼時 | 授權碼、裝置名稱（如「Windows・Chrome」）、實例代碼；Lemon Squeezy 回傳方案、到期日、購買 Email、已啟用裝置數等 |
| **你要下載的網站**（影片、串流、字幕所在的伺服器） | 你按下下載、預覽、錄製或匯出字幕時 | 由你的瀏覽器直接向該網站請求，等同你在該網站觀看影片；該網站會看到你的 IP 位址與請求。**不會經過我們的伺服器**。在 YouTube 頁面，本工具會向 YouTube 請求影片的格式清單 |

## 4. 解除安裝感謝頁面

為了在你移除擴充功能後自動釋出授權名額，本工具會設定一個「移除後開啟的頁面」。該網址的 `#` 片段（fragment）內帶有你的授權資訊。依網頁標準，`#` 之後的內容**不會**隨請求送到 GitHub 的伺服器；頁面中的程式只在你的瀏覽器內讀取它，並直接向 Lemon Squeezy 要求登出該裝置，隨後清除網址中的片段。若你未啟用 Pro，網址不含任何授權資訊。

## 5. 權限用途說明

本工具要求的瀏覽器權限，只用於其核心功能：

- **所有網站存取、webRequest、內容腳本**：在你瀏覽的頁面中找出影片與串流網址、字幕軌；分析在本機完成，不會上傳。
- **downloads、unlimitedStorage、offscreen**：下載檔案、暫存片段並在背景合併、轉檔。
- **tabCapture**：僅在你按下「錄製」時錄製目前分頁。
- **declarativeNetRequest**：為少數需要來源標頭的影片請求補上標頭。
- **scripting、activeTab、tabs**：讀取目前分頁的標題與狀態，並抓取頁面上的字幕資訊。
- **sidePanel、storage**：側邊欄介面與保存設定。
