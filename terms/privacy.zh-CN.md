# 隐私权政策

> 本简体中文版为便利阅读的译本，内容如与繁体中文版有出入，以繁体中文版为准。

最后更新：2026 年 10 月 14 日

本政策说明 **Video Lasso**（以下称「本工具」）及其官方网站如何处理数据。本工具由个人开发者许耀庭（以下称「开发者」或「我们」）开发与维护。我们依《个人数据保护法》（以下称「个资法」）等中华民国（台湾）法律处理个人数据。使用本工具即表示你了解本政策；使用条件请见[服务条款](terms.html)。

**简单说：** 本工具在你的浏览器里运作，没有帐号、没有分析追踪，我们也没有接收你浏览纪录或视频内容的服务器。只有在你激活 Pro 授权码时，才会与付款平台 Lemon Squeezy 往来。

> **仅限本机处理（Local Processing Only）：** 所有视频的解析、裁切与下载进程，均在你的浏览器本机（由本工具在你自己的电脑上）完成。任何媒体内容、来源网址或视频数据，**都不会被发送至、也不会被保存于我们的服务器**——我们并没有这样的服务器。
>
> **零追踪（Zero User Tracking）：** 我们**不收集、也不出售**你的浏览历史纪录（Browsing History）。

## 1. 我们「不」搜集的数据

- 你浏览的网址、网页内容与搜索纪录。
- 你侦测、下载、录制的视频、音频或字幕内容，以及下载清单。
- 你的姓名、帐号、定位、设备识别码，或任何使用行为分析与广告数据。
- 你的信用卡等付款信息（由 Lemon Squeezy 处理，我们不会取得）。

本工具没有内置任何统计、分析、广告或错误回报服务。

**数据收集范围：** 本工具不收集用户数据。唯一的例外是 Pro 授权验证：当你激活授权码时，授权码与设备名称会直接送往 Lemon Squeezy 验证（见第 3 条）。本工具没有崩溃回报（crash report）、遥测或使用统计。我们不会出售、出租或与任何人交换你的数据。

## 2. 保存在你自己浏览器中的数据

下列数据只存在你的浏览器内（`chrome.storage` 与 IndexedDB），开发者无法读取：

| 数据 | 用途 | 存放位置 |
| --- | --- | --- |
| 偏好设置（语言、主题、字体、预览方式、字幕语言偏好、Logo 与图标颜色） | 保存你的设置 | storage.local |
| 目前分页侦测到的视频网址与标题（暂时性） | 显示可下载清单 | storage.session（关闭浏览器即清除） |
| 下载进度与最近 200 笔下载纪录（标题、缩略图、来源页网址、文件名、大小、时间） | 显示「进行中」与「纪录」 | storage.local，可在扩充功能内删除 |
| 你选择的保存文件夹的访问权（文件夹句柄） | 把文件存到你指定的位置 | IndexedDB |
| 今日剪辑与录制的使用次数 | 实施免费版每日限制 | storage.local 与 storage.sync |
| 高级下载额度计数（剩余次数、下次补充时间） | 实施免费版高级下载额度 | storage.local 与 storage.sync |
| Pro 授权信息（授权码、方案、到期日、Email、设备名称、已激活设备数、最近验证时间） | 激活并维持 Pro 功能 | storage.local |

说明：

1. **storage.sync** 由你的浏览器帐号（Google 或 Microsoft）提供，内容可能被同步到你登录同一帐号的其他设备，并保存在该公司的服务器；这属于浏览器的功能，不由我们控制，开发者也无法访问。本工具只把「今日剪辑与录制次数」放进 sync，目的是避免重新安装后次数被归零。
2. 卸载扩充功能后，上述本机数据会由浏览器一并删除。

## 3. 会发送到外部的数据

本工具只在下列情况与外部连接：

| 对象 | 何时 | 发送内容 |
| --- | --- | --- |
| **Lemon Squeezy**（api.lemonsqueezy.com） | 你激活、定期验证或注销授权码时 | 授权码、设备名称（如「Windows・Chrome」）、实例代码；Lemon Squeezy 回传方案、到期日、购买 Email、已激活设备数等 |
| **你要下载的网站**（视频、串流、字幕所在的服务器） | 你按下下载、预览、录制或导出字幕时 | 由你的浏览器直接向该网站请求，等同你在该网站观看视频；该网站会看到你的 IP 地址与请求。**不会经过我们的服务器**。在 YouTube 页面，本工具会向 YouTube 请求视频的格式清单 |
| **GitHub Pages**（yaotingshiu.github.io） | 你打开官方网站，或卸载后浏览器打开感谢页面时 | 一般网页请求（IP、浏览器类型），由 GitHub 依其政策处理 |

## 4. 卸载感谢页面

为了在你移除扩充功能后自动发布授权名额，本工具会设置一个「移除后打开的页面」。该网址的 `#` 片段（fragment）内带有你的授权信息。依网页标准，`#` 之后的内容**不会**随请求送到 GitHub 的服务器；页面中的程序只在你的浏览器内读取它，并直接向 Lemon Squeezy 要求注销该设备，随后清除网址中的片段。若你未激活 Pro，网址不含任何授权信息。

## 5. 权限用途说明

本工具要求的浏览器权限，只用于其内核功能：

- **所有网站访问、webRequest、内容脚本**：在你浏览的页面中找出视频与串流网址、字幕轨；分析在本机完成，不会上传。
- **downloads、unlimitedStorage、offscreen**：下载文件、暂存片段并在背景合并、转档。
- **tabCapture**：仅在你按下「录制」时录制目前分页。
- **declarativeNetRequest**：为少数需要来源标头的视频请求补上标头。
- **scripting、activeTab、tabs**：读取目前分页的标题与状态，并抓取页面上的字幕信息。
- **sidePanel、storage**：侧边栏接口与保存设置。

4. **利用期间、地区、对象及方式**：自你激活授权起，至你注销、卸载或授权失效为止；地区为 Lemon Squeezy 及你的浏览器帐号供应商所在地；对象为你本人、Lemon Squeezy（以验证授权）与必要的客服往来；方式为电子方式处理。**这些数据主要存在你自己的浏览器，开发者不另行创建数据库。**

## 7. 官方网站

官方网站是静态网页，托管于 GitHub Pages，**不使用分析或追踪工具**。网页只在你的浏览器的 localStorage 记住语言选择。结帐表单由 Lemon Squeezy 以内嵌方式提供，其收集的数据与使用的 Cookie 由 Lemon Squeezy 依其隐私政策处理。网页会从 cdnjs 加载开源函数库，该服务可能记录一般的访问纪录。

## 8. 数据安全与保存

- 授权码在接口上仅显示屏蔽后的内容；与 Lemon Squeezy 的连接采用 HTTPS。
- 本机数据的安全性取决于你的电脑与浏览器帐号的安全，请妥善保管授权码，勿公开张贴。
- 我们不保存你的数据；你来信联系时，信件内容仅用于回复与处理问题，处理完毕后可应你要求删除。

## 9. 儿童

本工具并非针对儿童设计。我们不会刻意搜集儿童的个人数据。
