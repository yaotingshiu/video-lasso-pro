本ポリシーは、**Video Lasso**（以下「本ツール」）および公式ウェブサイトが、データをどのように取り扱うかを説明するものです。本ツールは、個人開発者の許耀庭（Hsu Yao Ting。以下「開発者」または「当方」）が開発・運営しています。当方は、中華民国（台湾）の個人情報保護法（以下「PDPA」）をはじめとする法令に従って、個人情報を取り扱います。本ツールを利用することで、利用者は本ポリシーを確認したものとみなされます。利用条件については[利用規約](terms.html)をご覧ください。

**要点：** 本ツールはお使いのブラウザの中で動作します。アカウントもアクセス解析もなく、閲覧履歴や動画の内容を受け取るサーバーも運営していません。本ツールが利用者に関して通信する相手は、決済プラットフォームの Lemon Squeezy だけで、それも Pro のライセンスキーを有効化するときに限られます。

## 1. 収集しない情報

- 閲覧したページのアドレスや内容、検索内容。
- 検出、ダウンロード、録画した動画・音声・字幕、およびダウンロードの一覧。
- 氏名、アカウント、位置情報、端末の識別子、利用状況の分析データ、広告データ。
- クレジットカードなどの支払い情報（Lemon Squeezy が処理するため、当方は受け取りません）。

本ツールには、統計、アクセス解析、広告、クラッシュ報告のいずれのサービスも組み込まれていません。

## 2. お使いのブラウザ内に保存されるデータ

次のデータはお使いのブラウザ内（`chrome.storage` と IndexedDB）に保存され、開発者が読み取ることはできません。

| データ | 目的 | 保存場所 |
| --- | --- | --- |
| 設定（言語、テーマ、文字サイズ、プレビューモード、字幕の優先言語、ロゴとアイコンの色） | 設定を記憶するため | storage.local |
| 現在のタブで検出された動画のアドレスとタイトル（一時的） | ダウンロード可能な項目の一覧を表示するため | storage.session（ブラウザを閉じると消去） |
| ダウンロードの進行状況と直近 200 件のダウンロード記録（タイトル、サムネイル、元のページのアドレス、ファイル名、サイズ、日時） | 「進行中」と「履歴」を表示するため | storage.local。拡張機能内で削除できます |
| 選択した保存先フォルダへのアクセス（フォルダのハンドル） | 指定した場所にファイルを保存するため | IndexedDB |
| 本日の切り出しと録画の回数 | 無料版の 1 日あたりの上限を適用するため | storage.local と storage.sync |
| プレミアムダウンロードの枠のカウンター（残り回数、次の回復時刻） | 無料版のプレミアムダウンロードの枠を適用するため | storage.local と storage.sync |
| Pro のライセンス情報（キー、プラン、有効期限、メールアドレス、端末名、使用中の端末、最終確認時刻） | Pro を有効化し、動作させ続けるため | storage.local |

補足：

1. **storage.sync** は、お使いのブラウザアカウント（Google または Microsoft）が提供する機能です。内容は、同じアカウントでサインインしている他の端末に同期され、その企業のサーバーに保存されることがあります。これはブラウザの機能であり、当方は管理できず、開発者がアクセスすることもできません。本ツールが同期に載せるのは「本日の切り出しと録画の回数」だけで、再インストールしても回数がリセットされないようにするためです。
2. 拡張機能を削除すると、ブラウザが上記のローカルデータも一緒に削除します。

## 3. 第三者に送信されるデータ

本ツールが外部に接続するのは、次の場合に限られます。

| 相手 | 接続するとき | 送信される内容 |
| --- | --- | --- |
| **Lemon Squeezy**（api.lemonsqueezy.com） | ライセンスキーの有効化、定期的な確認、サインアウトのとき | ライセンスキー、端末名（「Windows · Chrome」など）、インスタンス ID。Lemon Squeezy からは、プラン、有効期限、購入時のメールアドレス、使用中の端末が返されます |
| **ダウンロード元のサイト**（動画、ストリーム、字幕をホストしているサーバー） | ダウンロード、プレビュー、録画、字幕の書き出しをするとき | お使いのブラウザが直接リクエストします。そのサイトで動画を視聴する場合と同じで、そのサイトには IP アドレスとリクエストが見えます。**当方のサーバーを経由することはありません。** YouTube のページでは、本ツールが YouTube に動画の形式一覧を問い合わせます |
| **GitHub Pages**（yaotingshiu.github.io） | 公式ウェブサイトを開いたとき、または削除後にブラウザがお礼のページを開くとき | 通常のウェブリクエスト（IP アドレス、ブラウザの種類）。GitHub が自社のポリシーに従って処理します |

## 4. 削除後に表示されるページ

拡張機能を削除した後にライセンスの枠を自動で空けるため、本ツールは「削除後に開くページ」を設定します。ライセンス情報は、そのアドレスの `#` 以降（フラグメント）に含まれます。ウェブの標準仕様では、`#` 以降は GitHub のサーバーには**送信されません**。ページ上のスクリプトは、それをお使いのブラウザの中でのみ読み取り、Lemon Squeezy に直接問い合わせて端末をサインアウトし、その後フラグメントを消去します。Pro を有効化していない場合、アドレスにライセンス情報は含まれません。

## 5. 各権限が必要な理由

本ツールが要求するブラウザの権限は、主要な機能のためだけに使われます。

- **すべてのサイトへのアクセス、webRequest、コンテンツスクリプト**：閲覧中のページで、動画やストリームのアドレス、字幕トラックを見つけるため。解析はお使いの端末内で行われ、アップロードされません。
- **downloads、unlimitedStorage、offscreen**：ファイルの保存、セグメントの一時保管、バックグラウンドでの結合・変換のため。
- **tabCapture**：現在のタブの録画のため。「録画」を押したときだけ使用します。
- **declarativeNetRequest**：一部の動画リクエストに必要なヘッダーを追加するため。
- **scripting、activeTab、tabs**：現在のタブのタイトルと状態を読み取り、ページ上の字幕情報を取得するため。
- **sidePanel、storage**：サイドパネルの画面と、設定の保存のため。

## 7. 公式ウェブサイトについて

公式ウェブサイトは静的なサイトで、GitHub Pages 上で公開されており、**アクセス解析や追跡ツールは使用していません**。言語の選択を、お使いのブラウザの localStorage に記憶するだけです。決済フォームは Lemon Squeezy から埋め込まれており、そこで収集されるデータや使用される Cookie は、Lemon Squeezy が自社のプライバシーポリシーに従って取り扱います。各ページは cdnjs からオープンソースのライブラリを読み込んでおり、cdnjs 側で通常のアクセスログが保管されることがあります。
